# Lists 2.0 visual review

Screenshots captured from a local test-auth build with isolated sample lists and market data. These illustrate the Labs Lists 2.0 update, not production accounts or live prices.

- [List directory](list-directory.png): consistent cards and arrows on both View items buttons.
- [Device toolbar](device-toolbar.png): adjacent Prices in / Buy from controls, followed by Refresh prices, with undo/redo at the right edge.
- [Online toolbar](online-toolbar.png): matching labels, control heights, and history placement.
- [Mobile build view](device-mobile.png): wrapped controls and a collapsible add-items panel.
- [Mobile notifications](notifications-mobile.png): settings fit within the viewport.
- [Sharing dialog](sharing.png): clear permissions and consistent form styling.
- [Active shopping trip](shopping-trip.png): route comparison collapses after selection; Change route brings it back.

Toolbar screenshots show the final alignment refinements. Dialog and Shop screenshots were captured earlier in the same review; their backgrounds can show an earlier toolbar layout.
